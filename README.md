# Squirrel Eat Squirrel (Web Edition)

A survival arcade game built with Python and Pygame-CE. Eat smaller squirrels to grow larger and avoid getting eaten by bigger ones.

Playable locally and in modern web browsers via WebAssembly ([Pygbag](https://pygame-web.github.io/)).

## How to Run Locally

### Prerequisites
- Python 3.10+
- `pip install pygame-ce pygbag`

### Play Locally
```bash
python main.py
```

### Run in Browser Locally
```bash
python -m pygbag main.py
```
Open `http://localhost:8000` in your web browser.

## Controls
- **Arrow Keys** or **WASD**: Move squirrel
- **R**: Restart game
- **Escape**: Quit game
